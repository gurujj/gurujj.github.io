빌드: Visual Studio 2015 이상에서 `OffsetGen2.sln` 열기 -> Release 빌드 -> `OffsetGen2.rhp` 를 라이노에 설치.
Rhino 설치 폴더가 `C:\Program Files\Rhino 8\System` 이 아니면 `/p:RhinoDir="..."` 지정. 자세한 변경 내용은 `CHANGES`.
